PUBLISH USING GITHUB PAGES (FREE)
1. Sign in or create an account at https://github.com/
2. Create a new PUBLIC repository. For the simplest root URL, name the repository exactly:
   YOUR-GITHUB-USERNAME.github.io
   (Replace YOUR-GITHUB-USERNAME with your actual GitHub username.)
3. Upload index.html to the repository root (not inside another folder).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. GitHub will show the published website URL in Settings > Pages. It can take a few minutes.

IMPORTANT TRACKING NOTES
- No Google tag ID has been supplied yet, so tracking is not active in this first draft.
- Once Google Ads creates an AW-... ID (and optionally GA4 creates G-...), add the Google tag snippet in the <head> section where the placeholder comment is.
- The current page records phone_click and whatsapp_click events only after the Google tag is installed.
- For Google Ads website-call conversion reporting, create a website call-click conversion action in Google Ads and add its conversion event snippet/label. A click is not proof that a call connected.
- Calls from Google Ads call assets/call ads are configured separately in Google Ads using call reporting / call conversions, where eligible.
- Never paste your Google Ads password or account login details into website files.
